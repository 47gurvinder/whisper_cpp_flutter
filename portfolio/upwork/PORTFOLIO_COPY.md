## Project description — 526/600 characters

Built a production-ready Flutter plugin that brings whisper.cpp speech recognition to Android and iOS. It delivers private, fully offline transcription and translation, live microphone streaming, word-level timestamps, cancellation, Silero voice activity detection, and local speaker-turn detection. I implemented Dart APIs, C++ FFI/native bindings, audio resampling, resumable model downloads with SHA-256 verification, and mobile acceleration using Android CPU optimizations plus iOS Accelerate, Metal, and optional Core ML.
